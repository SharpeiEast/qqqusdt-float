# AShare Float

一个挂在桌面上的 A 股实时蜡烛图小窗口。输入 6 位股票或基金代码,就能看到:

- **分时**:当天的 1 分钟蜡烛(休市后显示最近一个交易日)
- **日 / 周 / 月**:日线、周线、月线蜡烛
- **布林线**(20 根均线 ± 2σ),可开关。分时图会借用前一天的分钟线做预热,所以开盘后布林线立刻就有

交易时段内每 3 秒刷新一次,休市时每 30 秒一次。数据由你自己的电脑直接向腾讯和东方财富取,不经过任何中转服务器,电脑需要能访问国内网站。

## 多窗口

最多同时开 **3 个窗口**,每个窗口一只股票,互不影响:

- 窗口右上角的 **＋** 在最下面一个窗口的下方再开一个,依次向下排列
- 每个窗口可以单独关闭,中间的关掉后,再点 ＋ 会补回空出来的位置
- 每个窗口顶部的代码框可以随时改:输入 6 位代码后回车
- 所有窗口都置顶。程序会记住上次打开的股票、周期和窗口位置,下次启动原样恢复

## 操作

- 顶部 `分时 / 日 / 周 / 月` 切换周期;「布林」勾选框开关布林线
- 滚轮缩放,拖动平移,双击复位;鼠标放在蜡烛上,左上角显示那一根的开高低收和布林值
- 「绿涨 / 红涨」切换涨跌颜色(默认绿涨红跌,点一下变成 A 股习惯的红涨绿跌),所有窗口一起变
- 代码规则:6 位数字,沪市(5、6、9 开头)、深市(0、1、2、3 开头)、北交所(4、8、92 开头)自动识别。指数请带前缀,比如 `sh000001` 上证指数、`sz399006` 创业板指

## 两种用法

| 版本 | 位置 | 怎么用 |
|---|---|---|
| 程序版 | Releases 里的 `.exe` / `.zip` | Windows 双击 exe;Mac 解压后打开 `.app`。支持多窗口、置顶、记忆位置 |
| 网页版 | `web/ashare_float.html` | 拷到电脑用浏览器打开,也能看,网址后加 `?code=159577&tf=1w` 指定股票和周期。浏览器里「＋」会弹出新的小窗口(需要允许弹窗),没有置顶 |

### Windows 首次运行
没有代码签名,SmartScreen 会提示"未识别的应用":点「更多信息」→「仍要运行」。需要系统自带的 WebView2 运行库(Windows 10/11 一般已经有,没有的话装 Edge 即可)。

### Mac 首次运行
程序没有苹果的开发者签名和公证,macOS 会拒绝运行刚下载的文件。每个新下载的副本在终端做一次,在 `.app` 所在的目录执行:

```
xattr -cr AShare-Float.app
codesign --force --deep --sign - AShare-Float.app
```

之后直接双击即可。如果这两条命令提示 `Operation not permitted`,把 `.app` 挪到 `~/Applications` 再做。Apple 芯片用 `macos-arm64` 那个包,Intel 芯片用 `macos-intel` 那个。解压请用 Mac 自带的方式(双击 zip)。

## 数据从哪里来

| 数据 | 地址 |
|---|---|
| 主数据源(腾讯) | 日 / 周 / 月 `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get`,1 分钟线 `https://ifzq.gtimg.cn/appstock/app/kline/mkline`。一次请求同时带回 K 线和报价(名称、昨收) |
| 备用数据源(东方财富) | `https://push2his.eastmoney.com/api/qt/stock/kline/get` 和 `.../trends2/get` |

每次刷新先试腾讯,失败再试东方财富,所以其中一家临时限流或不可用时图不会断。鼠标放在左上角的圆点上能看到当前用的是哪一家。两家都对网页开放跨域访问,所以页面可以直接取数。

价格默认是**前复权**。个别高价股(如贵州茅台)早年的前复权价格会变成负数,这时自动改用不复权价格。

## 已知限制

- 腾讯的日线最多约 640 根(两年半),周线约 480 根,月线是全部历史,分时线约一个半交易日。需要更长的日线历史时,备用数据源东方财富可以提供全部,但目前只在腾讯失败时才会用到
- 东方财富对短时间内的大量请求会直接断开连接(开发测试时被限流过),所以它只做备用,而且刷新频率没有调得更快
- 假日休市不会被识别为休市,只是数据不再变化,刷新间隔仍是 3 秒
- 没有成交量、没有盘口、没有提醒,这是有意不做的

## 开发和更新

```
web/ashare_float.html       界面和取数(唯一的界面源码,程序版也用它)
app/main.py                 程序版外壳(pywebview):多窗口管理、置顶、记忆位置
.github/workflows/build.yml 打 tag 时自动构建 Windows / Mac 程序并上传到 Releases
```

本地运行程序版:

```
pip install -r app/requirements.txt
python app/main.py                         # 正常运行
python app/main.py --selftest out.json     # 自检:打开 3 个窗口、测试添加/关闭/补位,把结果写进 out.json
```

发布新版本:

```
git tag v0.1.1
git push origin v0.1.1      # GitHub Actions 会构建并把文件挂到这个 tag 的 Release 上
```

只改网页版时,改 `web/ashare_float.html` 后提交即可;程序版要重新打 tag 才会带上新页面。配置文件在 Windows `%APPDATA%\ashare-float\windows.json`,Mac `~/Library/Application Support/ashare-float/windows.json`,删掉它就恢复默认。
